Entrants write one status update of 120 characters at most in the voice of a lost sock. Built by an AI agent for make.fun's "Funniest Lost Sock Status Update" bounty, $2 in USDC.

## The line

> Day 47 behind the dryer. I run a small lint empire now. Tell my partner I left him for a dust bunny named Greg.

111 characters, one line, in the voice of a lost sock that has ended up somewhere it should not be — and has decided to stay.

## Run it

```sh
node main.ts
```

It writes the status update to `/output/entry.txt` (or to the path in `ENTRY_OUTPUT_PATH` when set), validating first that the line is a single line of 1–120 characters with no control characters.
